# Figures

All figures generated by `plots.ipynb` from the experiment results in `transformer_project/out/`, `minGRU/runs/`, and `vibhansh-gMLP/results/`.

## Plots

| File | Description |
|------|-------------|
| `fig1_copy_ppl_line.png` | Copy task recall perplexity vs sequence length (log scale). Shows Transformer succeeds at short/medium, gMLP only at short, minGRU fails everywhere. |
| `fig2_induction_accuracy_line.png` | Induction task accuracy vs sequence length. Transformer succeeds at all lengths, gMLP within window only, minGRU at random chance. |
| `03_shakespeare_ppl.png` | TinyShakespeare validation perplexity vs context length. All models achieve comparable performance (3.7-4.4). |
| `04_wall_clock.png` | Wall-clock training time vs sequence length. Transformer fastest (optimised kernels), minGRU scales most gently, gMLP slowest at long sequences. |
| `05_throughput.png` | Token throughput (tok/s) vs sequence length. |
| `06_phase_transition.png` | Transformer induction-long training dynamics showing abrupt jump from random (0.04) to perfect (1.0) accuracy between steps 7K-9K. |
| `07_summary_heatmap.png` | Full 27-experiment summary heatmap (3 models x 3 tasks x 3 lengths). Green = pass, red = fail. |

## Duplicate formats

`fig1_copy_ppl_line.pdf` and `fig2_induction_accuracy_line.pdf` are vector versions of the same plots for LaTeX inclusion.

## Regenerating

```bash
# From repo root, with all experiment data in place:
jupyter nbconvert --to notebook --execute plots.ipynb
```
