# RNN's Revenge — minGRU

minGRU implementation for the COMP6242 paradigm comparison project. Direct reproduction of Feng et al. (2024) Appendix C.2 language modelling recipe.

## Architecture

- 4 layers, d_model=128, expansion_factor=1.0, mlp_mult=4.5
- Block structure: causal Conv1d (k=4) → minGRU cell → MLP
- Pre-norm RMSNorm, residual connections
- Parallel training via log-space cumulative sums
- Gate: g_t = σ(W·x_t) — input-only gating

## Setup

```bash
pip install -r requirements.txt
```

Data files are expected in `data/` (generated by the transformer project's data scripts or the `run_mingru.ipynb` notebook).

## Run

```bash
python scripts/train.py --exp mingru_tinyshakespeare_256
python scripts/train.py --exp mingru_tinyshakespeare_1024
python scripts/train.py --exp mingru_tinyshakespeare_2048
python scripts/train.py --exp mingru_longcopy_short
python scripts/train.py --exp mingru_longcopy_medium
python scripts/train.py --exp mingru_longcopy_long
python scripts/train.py --exp mingru_induction_short
python scripts/train.py --exp mingru_induction_medium
python scripts/train.py --exp mingru_induction_long
```

Or use `run_mingru.ipynb` on Google Colab (A100 runtime).

## Files

| File | Purpose |
|------|---------|
| `src/models/mingru.py` | minGRU model with parallel log-space scan |
| `src/training/trainer.py` | Training loop |
| `src/training/schedules.py` | Linear warmup + cosine decay |
| `src/training/logging_utils.py` | metrics.csv + console.log + meta.txt |
| `src/training/checkpointing.py` | Checkpoint save/resume |
| `src/eval/metrics.py` | PPL, masked PPL, masked accuracy |
| `scripts/train.py` | CLI entry point |
| `configs/experiments.py` | 9 named experiment configs |

## Output

Each run writes to `runs/<exp_name>__seed<N>__<timestamp>/`:
- `metrics.csv` — one row per eval step
- `config.txt` — hyperparameters
- `console.log` — training stdout
- `meta.txt` — git SHA, parameter count, full config
